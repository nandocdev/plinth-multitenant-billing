# Plinth Multi-Tenant Billing

> ⚠️ **Legacy package / architecture reference.**

This repository contains an earlier standalone billing package extracted from the Plinth SaaS work.

It is preserved publicly because the implementation demonstrates provider-agnostic billing, webhooks, usage metering and ledger concepts. It is not the canonical billing implementation for current NandocDev products.

## Status

- **Status:** legacy / reference
- **Production support:** none
- **Purpose:** architecture and package-design reference
- **Current SaaS work:** see the active [NandocDev repositories](https://github.com/nandocdev?tab=repositories)

## Concepts explored

- Provider-agnostic payment gateways
- Multi-tenant subscriptions
- One-time payments
- Usage metering
- Entitlements
- Webhook verification and processing
- Financial ledger concepts

> Do not treat the API or architecture in this repository as the current NandocDev contract.
